# Crown of Words

Tula's Island – Crown of Words is a mobile-first territory-control language-learning strategy game.

## Current status

Branch 1 establishes contracts and a minimal Vite scaffold only. Gameplay is intentionally not implemented yet.

## Source of truth

Read `TULAS_ISLAND_CROWN_OF_WORDS_MASTER_SPEC_2026-08-27.md` before implementation work.

## Local commands

```bash
npm install
npm run dev
npm test
```

GitHub Pages uses a configurable Vite base path so the standalone preview does not hard-code hosting assumptions into the game core.
